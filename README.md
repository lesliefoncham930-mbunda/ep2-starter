# EP2 – ESP32-S3 LED Blinking Project

**Student:** Leslie Mbunda  
**Course:** Embedded Programming 2 (EP2)  
**Board:** ESP32-S3 DevKitC-1  
**Development Environment:** VS Code with PlatformIO  
**Framework:** Arduino

## Project Description

This project demonstrates how to configure and program an
ESP32-S3 development board using PlatformIO.

The main task is to blink an LED and verify that the program
runs successfully on the physical development board.

## Hardware and Software

- ESP32-S3 DevKitC-1
- USB cable
- Visual Studio Code
- PlatformIO extension
- Arduino framework

## Project Structure

- `src/main.cpp` – Main application code
- `platformio.ini` – PlatformIO configuration
- `screenshots/` – Evidence of the working LED

## Testing

The LED blinking program was uploaded to the ESP32-S3 board.
The LED blinking operation was observed successfully.
